SDN • ML

DDoS Detection in SDN

Research project using Mininet to simulate SDN environments and evaluate resilience with ML/DL models.

GitHub

Project Overview

Intelligent DDoS detection and mitigation for SDN using Mininet, Ryu, and OpenFlow. Uses centralized control to monitor traffic, detect anomalies via ML, and auto‑install blocking rules.

Problem Statement

  • Traditional networks lack real‑time detection and centralized visibility.
  • Routing rules are slow to adapt during volumetric floods.

System Architecture

  • Data Plane: OpenFlow switches in Mininet; hosts generating normal + attack traffic
  • Control Plane: Ryu Controller with custom detection logic
  • Application: ML‑based detection + flow analyzer + mitigation engine

Core Functionalities

  • Custom SDN topologies and traffic scenarios in Mininet.
  • Flow stats collection: packet/byte counts, duration, rates, src/dst IPs.
  • Dataset generation from normal vs. simulated DDoS (ICMP/UDP floods).
  • Models including Random Forest and complementary ML/DL approaches.
  • Automatic mitigation by installing drop rules via the controller.
